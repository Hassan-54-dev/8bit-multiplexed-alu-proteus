# 8-Bit Multiplexed ALU with 7-Segment Display (Proteus Simulation)

Designed and simulated a fully functional 8-bit Arithmetic Logic Unit (ALU) using discrete digital logic and multiplexers in Proteus.

## 🚀 Project Overview
This project routes 8-bit inputs ($A$ and $B$) using efficient multiplexer logic to manage operational pathways and data flow control, outputting final calculation results directly onto dual 7-segment displays.

## 🛠️ Key Features
- **Combinational Circuit Design:** Built entirely using logic gates, adders/subtractors, and MUX/DEMUX components without relying on microcontrollers.
- **Multiplexed Data Routing:** Efficiently handles 8-bit data paths and control signals.
- **Visual Output:** Integrated a multiplexed display mechanism for real-time visualization on dual 7-segment displays.
